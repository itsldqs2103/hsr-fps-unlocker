# Honkai: Star Rail FPS Unlocker

A simple script that unlocks the **120 FPS** graphics option in _Honkai: Star Rail_ and launches the game.

## How to Use

1. Download the latest `HSRFPSUnlocker-vX.X.X.zip` from the **Releases** page.
2. Extract the downloaded `.zip` file.
3. Open the extracted folder and run `HSRFPSUnlocker.exe`.
4. On your first run, a window will pop up—select your `StarRail.exe` file.
5. The script will update your registry to **120 FPS** and start the game automatically.

---

## How It Works

- **Auto-detects Game Path:** Remembers your `StarRail.exe` location so you only have to pick it once.
- **Safe Registry Tweak:** Changes the internal graphics setting from `30`, `60` to `120` FPS in `HKCU:\Software\Cognosphere\Star Rail`.
- **Auto Launch:** Starts the game immediately after applying the FPS limit.
